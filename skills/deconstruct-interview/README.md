# 🧠 deconstruct-interview (面试问题解构器)

这是一个专为 AI 编码助手设计的自定义技能，用于对各类面试问题（包括技术原理型、架构设计与折中型、行为面试型）进行系统、深度的解构。

它能够生成客观、科学的 10 分制量化回答评估量表，剖析提问背后的深层目的，并对问题复杂度进行定级，以辅助面试官快速建立筛选依据，或帮助候选人进行系统性的求职准备。

## 🛠️ 核心功能与四大模块

当触发此技能后，AI 将严格按照以下四大模块输出解构结果：

1. **🌐 知识背景与底层原理**：包含技术的引入背景（Why/When）、解决的核心痛点（What）、底层工作机制（How，支持 Mermaid 图表展示）、典型应用场景（Where）、性能/设计的折中权衡（Trade-offs）以及潜在的避坑陷阱（Pitfalls）。
2. **🎯 面试官的真实提问目的**：解构提问的表层目的（八股文记忆）与深层目的（实际踩坑经验、系统性权衡思维、抗压能力等），并指明初中级与高级/专家候选人回答时的“区分度分水岭”。
3. **📊 科学 10 分制评估体系**：设计一套结构化的 10 分制评分量表（表格形式），将回答拆分为 3-5 个核心要点，明确给出每个要点在不同回答表现下的拿分标准和扣分项。
4. **🧠 问题复杂度评级**：给出 5 星制复杂度定级，并阐明评级依据及目标受众候选人层级。
