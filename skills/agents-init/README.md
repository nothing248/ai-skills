# agents-init (项目规则初始化与同步技能)

`agents-init` 是一个专为 AI 编码助手定制的项目规则初始化技能。

在复杂开发项目中，后续介入的 AI 助手往往因为对项目背景和技术细节了解不深，容易编写不规范、风格冲突的代码。该技能允许 AI 助手通过解析项目现有的需求设计文件和技术架构文档，自动、规范地生成面向 AI 助手的项目级自定义规则文件（`.agents/AGENTS.md`）。

---

## 📂 技能结构

本技能保存在项目的根目录的 `skills` 文件夹下：
```
skills/agents-init/
├── SKILL.md       # 技能的主体执行逻辑与工作流
├── README.md      # 本说明文档
└── evals/
    └── evals.json # 针对该技能的自动化评测测试用例
```

由于本技能被安置在非标准定制路径（项目根目录的 `skills/` 下），在项目的 `.agents/skills.json` 配置文件中已经声明了对此目录的引用以实现自动加载。

---

## ⚙️ 工作流程 (Workflow)

当技能被唤起时，AI 助手将遵循以下流程：

1. **自动文件检索 (File Inspection)**:
   - 优先检索项目根目录的 `prd.md`（产品需求文档）与 `tech-stack.md`（技术架构文档）。
   - 如果对应文件不存在，则会遍历工作区搜索同类功能的文件（如 `README.md`、`architecture.md`）。如果均不存在，将主动提示用户提供基本需求。

2. **精炼业务与技术约束 (Information Extraction)**:
   - 从 PRD 中提取：核心目标、核心业务流、业务逻辑禁止事项等。
   - 从 Tech Stack 中提取：依赖栈版本、代码目录规范、API 规范、禁止调用的包等。

3. **规则整合 (Synthesis & Compilation)**:
   - 将上述内容整合成直接面向 AI Agent 动作的指令（例如："你必须做 X", "绝对不能做 Y"）。

4. **规范落盘 (Writing AGENTS.md)**:
   - 自动在项目目录下创建 `.agents/AGENTS.md` 规则规范。

---

## 🎯 触发场景与使用方法 (Triggers)

本技能已被项目自动加载，您无需手动安装。当您需要更新或创建项目规则时，可以直接对助手输入以下指令：

- **初始化项目规则**：
  > *"我想根据当前项目的 md 说明文件初始化项目规则"*
- **同步/更新规格**：
  > *"我们的 PRD/技术栈发生了变动，请重新生成并同步 `.agents/AGENTS.md` 规则文件"*

---

## 🛡️ 自动化评测 (Evaluation)

我们在 `evals/evals.json` 中配置了三个自动化测试场景，用以比对**使用本技能**与**一般基础表现**的区别：
- `standard-init`（标准初始化）
- `fallback-readme`（兜底读取 README）
- `update-rules`（规则合并与更新）

这些测试用例能保证该技能在长期迭代中，功能不发生衰退。
