# deconstruct (信息解构与脱水阅读技能)

`deconstruct` 是一个专为 AI 编码/阅读助手定制的**极度理性的内容“脱水解构器”**。

在海量信息时代，人们经常被长篇大论、名人故事、感性鸡汤或说教包装所淹没，导致获取干货的效率低下。该技能旨在剥离输入内容的包装和噪音，将其精确拆解为四种基本元素（信息、客观观点、主观立场、故事垫片），以最高的信噪比（Signal-to-Noise Ratio）呈现给用户，从而升级用户的认知系统并提供脱水阅读决策。

---

## 📂 技能结构

本技能保存在项目的根目录 `skills` 文件夹下：
```text
skills/deconstruct/
├── SKILL.md       # 技能的主体执行逻辑与输出模板规范
├── README.md      # 本说明文档
└── evals/
    └── evals.json # 针对该技能的自动化评测测试用例 (包含 4 个典型场景)
```

由于本技能被安置在项目根目录的 `skills/` 下，在项目的 `.agents/skills.json` 配置文件中已经声明了对此目录的引用以实现自动加载。

## ⚙️ 工作流程 (Workflow)

当技能被唤起时，AI 助手将遵循以下流程进行理性的内容提取和输出，直接给出结果，禁止任何寒暄（如“好的”、“下面为您总结”等）：

1. **💡 一句话核心**：
   - 使用不超过 50 字的极凝练、高密度的学术/专业语言概括文章核心论点。

2. **📊 要素一：核心事实 (Information)**：
   - 仅用 Bullet Points 罗列客观存在的硬事实、物理数据、历史记录、实验结果等可被第三方证伪的内容。若无，标记“无显著硬事实”。

3. **⚙️ 要素二：逻辑算法与客观观点 (Objective Views)**：
   - 提取作者基于事实推导出的可复用思维模型和因果关系（以 `A -> B` 形式抽象其因果机制模型），并进行 1-2 句话阐述。

4. **⚠️ 要素三：主观立场与价值偏好 (Subjective Views)**：
   - 识别作者的道德偏好、情感倾向、或无逻辑支撑的偏见，并一句话给出【避坑提示】（指出其是否用“主观偏好”伪装成“客观规律”或存在情绪绑架）。

5. **📦 要素四：故事与垫片 (Stories & Padding)**：
   - 过滤作者引入的个人经历、名人八卦、比喻等案例细节，仅用 2-3 个字将案例名称列入已过滤垫片，并标记为 `[已跳过细节]`。

6. **🎯 脱水阅读决策建议**：
   - 一句话评估本文是否值得花时间深度精读，并简要陈述原因。

## 🎯 触发场景与使用方法 (Triggers)

本技能已被项目自动加载。当您需要阅读、总结、精炼文章时，可以直接对助手输入以下指令：

*   **文本脱水与提纯**：
    > *“帮我把这篇长文脱水读一下，过滤废话只留干货”*
*   **内容结构化解构**：
    > *“解构一下这篇商业博客的逻辑模型和作者夹带的主观偏见”*
*   **链接或文档去噪提取**：
    > *“解构一下这个链接里的文章：https://example.com/article”*
    > *“帮我对 ./docs/report.pdf 进行信息解构”*

## 🛡️ 自动化评测 (Evaluation)

我们在 `evals/evals.json` 中配置了 4 个具有代表性的评测用例：
1. **`eval-0` (故事鸡汤型)**：《为什么你必须坚持早起：成功的唯一秘密》
2. **`eval-1` (硬核学术型)**：《海马体与睡眠巩固：短期记忆转化为长期记忆的突触机制》
3. **`eval-2` (混合商业分析)**：《瑞幸咖啡的兴衰：商业逻辑与泡沫游戏》
4. **`eval-3` (新闻特写长文)**：《十年脱欧路：一名英国人的账单与失落》

这些评测用例确保了本技能在应对各种文章风格时，都能实现高水准的去噪输出和完美的格式约束。
