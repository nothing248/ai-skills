# 极简网盘系统项目规则

本项目是一个极简网盘系统，为个人用户提供安全、快速的云端文件存储与分享服务。为了确保开发质量与风格一致，AI 助手在开发和维护本项目时必须严格遵守以下规则与规范：

## 1. 业务目标与约束

### 1.1 核心功能
*   用户注册与登录。
*   文件上传、下载、删除。
*   提取码分享链接生成。

### 1.2 业务约束
*   **文件大小限制**：单个文件大小不能超过 `50MB`。
*   **链接有效期**：分享链接必须设置过期时间，最长不超过 `7天`。
*   **合规性**：禁止存储任何违反法律法规的文件。

## 2. 技术栈设计

本项目采用以下技术栈进行构建：
*   **前端**：Next.js 14 (React 18), TypeScript, Tailwind CSS
*   **后端**：Next.js API Routes (App Router)
*   **数据库**：Supabase (PostgreSQL)，必须使用 **Prisma ORM** 进行所有数据库操作。

## 3. 开发规范与目录规范

### 3.1 目录结构规范
所有新增或修改的文件必须放置在以下约定的目录下：
*   **组件**：必须放在 `/components` 目录下。
*   **页面与路由**：使用 App Router 规范，统一放在 `/app` 目录下。
*   **工具函数**：通用的工具类函数必须放在 `/utils` 目录下。

### 3.2 编码与接口规范
*   **API 风格**：所有 API 接口的设计和实现必须符合 RESTful 风格。
*   **错误处理**：
    *   API Route 必须捕获所有可能发生的错误，并返回统一的 JSON 格式错误信息。
    *   在生产环境中，**禁止**使用 `console.log` 打印任何日志或调试信息。
